# ChatGPT wealth requests

The ChatGPT GitHub plugin creates one new `<request_id>.json` here on the repository's
verified private default branch. Do not put real financial information in a public
repository. Processing is disabled in `config/wealth-requests.json` by default.

Read [the operator guide](../../docs/chatgpt-wealth.md) and the request JSON schema
before submitting a request. Request IDs and contents are immutable; corrections
use a new ID. Receipt: `reports/requests/<request_id>.json`.
